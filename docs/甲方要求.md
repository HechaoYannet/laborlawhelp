# 第一部分 演示参考案例

## 一、案例选型说明

本次演示选用 **"被违法辞退的普通劳动者"** 场景，理由如下：

- 这是商业计划书附录中最典型、最适合平台承接的入口场景
- 涵盖全部核心功能链路：问诊→要素抽取→规则测算→文书生成→分流转介
- 当事人情绪强、事实散，最能体现平台"前端整理"的独特价值
- 赔偿金额测算直观（违法解除赔偿金 = 经济补偿标准的二倍），容易让评委/合作方感受到产品实际价值
- 同时涉及社保补缴等附带主张，适合展示平台处理多主张场景的能力

## 二、案例基本信息

**案例名称：张女士违法解除劳动合同案**

| **要素**                         | **内容**                                                                                   |
| -------------------------------- | ------------------------------------------------------------------------------------------ |
| 用户                             | 张女士，30岁，普通行政文员                                                                 |

### 陕西本地化规则口径说明：工资基数以"到手工资"为准

根据 **《陕西省高级人民法院关于审理劳动争议案件若干问题的解答》**（陕高法〔2020〕118号）第18条规定：

> "劳动者的月工资包括基本工资、奖金、提成、津贴、补贴、加班工资等货币性收入，**不包括用人单位代扣代缴的个人所得税和应由个人缴纳的社会保险费。** "

这意味着，在陕西口径下，经济补偿/赔偿金的月工资基数应以劳动者实际到手的工资（银行流水金额）为准，而非合同约定的税前工资。因此，本案例中：

- 合同约定税前工资6,500元/月，但扣除个税及个人社保后，银行实发约5,600元/月
- 按陕西口径，经济补偿/赔偿金的月工资基数应按到手工资5,600元计算，而非税前6,500元
- 这一差异在其他省份可能不同，体现了平台"本地化规则包"的核心价值

- 新增"到手工资与合同约定工资的差额"问题，为后续本地化规则计算提供关键输入
- 不同案型进入不同分支，避免用户一上来就陷入信息过载

## 步骤4：本地规则引擎测算（约1-2分钟）

**展示内容**

规则引擎根据陕西本地口径自动测算赔偿项目。

### 关键口径说明：月工资基数以"到手工资"为准

本平台采用陕西省高院《解答》第18条口径，月工资基数以劳动者实际到手工资（银行流水金额）为准，不包含个人所得税和个人社保缴纳部分。因此本案测算采用到手工资5,600元而非税前6,500元。

### 赔偿测算结果

| **测算项**                 | **结果**                                                       |
| -------------------------- | -------------------------------------------------------------- |
| 工作年限                   | 2年1个月 → 经济补偿按2.5个月计算                               |
| 月工资基数（到手）         | 5,600元（按银行实发金额，非合同约定税前6,500元）               |
| 违法解除赔偿金             | 5,600 × 2.5 × 2 = **28,000元**                                 |
| 如按税前工资计算（对比）   | 6,500 × 2.5 × 2 = 32,500元（差额4,500元）                      |
| 可另主张                   | 补缴2025年3月至4月社会保险                                     |
| 仲裁时效提醒               | 自知道或应当知道权利被侵害之日起1年内                          |

**规则来源标注**：《劳动合同法》第47条、第87条；《陕西省高级人民法院关于审理劳动争议案件若干问题的解答》（陕高法〔2020〕118号）第18条

**讲解要点**

- 测算不是模型自由推理，而是规则引擎按预设条件与参数计算，保障稳定性
- 本地口径是核心差异点：陕西口径以"到手工资"为准，不包含个税和个人社保，与部分省份以税前工资为准的做法不同
- 如果不采用本地口径而按税前工资计算，赔偿金会高出4,500元，这正是本地化规则包的价值所在
- 金额明确标注为测算值，不等于最终裁判结果，体现合规边界意识

# 附录 陕西省本地化规则口径说明

## 一、核心法规依据

**《陕西省高级人民法院关于审理劳动争议案件若干问题的解答》**  
（陕高法〔2020〕118号，2020年12月18日施行）

## 二、第18条原文

**问：如何确定解除或终止劳动合同经济补偿的月工资基数？**

答：根据《中华人民共和国劳动合同法》第四十七条第三款的规定，经济补偿按照劳动者在解除或者终止劳动合同前十二个月的平均工资作为月工资基数进行计算，但不得低于当地最低工资标准。月工资基数无需分段计算。工作不满十二个月的，经济补偿按照劳动者实际工作月数的平均工资作为月工资基数进行计算，但不得低于当地最低工资标准。劳动者在解除或终止劳动合同前十二个月未工作且无工资收入，或者用人单位在停工期间向劳动者发放基本生活费，且低于当地最低工资标准的，经济补偿按照当地最低工资标准作为月工资基数进行计算。

劳动者的月工资包括基本工资、奖金、提成、津贴、补贴、加班工资等货币性收入，**不包括用人单位代扣代缴的个人所得税和应由个人缴纳的社会保险费。**

## 三、对本案例的具体影响

| **项目**                       | **金额/内容**                         | **说明**                                   |
| ------------------------------ | ------------------------------------- | ------------------------------------------ |
| 合同约定税前工资               | 6,500元/月                            | 不作为陕西口径下的计算基数                 |
| 银行实发到手工资               | 约5,600元/月                          | 按陕西口径作为计算基数                     |
| 按到手工资计算赔偿金           | 5,600 × 2.5 × 2 = **28,000元**       | 陕西口径正确结果                           |
| 按税前工资计算赔偿金（对比）   | 6,500 × 2.5 × 2 = 32,500元           | 如不采用本地口径的计算结果                 |
| 口径差异                       | **4,500元**                           | 本地化规则包的直接价值体现                 |

## 四、本地化规则包的价值总结

- 同一案例，按税前工资计算赔偿金32,500元，按陕西到手工资口径计算为28,000元，差额4,500元
- 如果平台不采用本地口径，输出结果将与实际裁判口径不一致，影响平台可信度
- 这一差异恰恰证明了"智裁"坚持本地化规则包的必要性和实际价值
- 律师端也能清楚看到：平台不是简单接入一个大模型，而是把本地口径嵌入了规则引擎
